# Basmala — component previews

Thumbnails for the section picker of **Basmala (بسملة)**, a Salla Twilight theme
for books, courses, services and digital products. Salla shows a component's
preview from an absolute public URL, so the images live here and are served by
jsDelivr:

```
https://cdn.jsdelivr.net/gh/fadisowan/basmala-previews@main/<component>.png
```

Generated from the theme's own templates (`pnpm run previews` in the theme
repository). Sample photographs are from Unsplash.

صور معاينة مكوّنات ثيم «بسملة» في منتقي أقسام سلة.
